# 🌐 Red Corporativa Multi-Sede Segura

## 📜 Descripción
Proyecto integrador universitario enfocado en el diseño e implementación de una red corporativa multi-sede, segmentada por regiones y áreas funcionales, garantizando seguridad, fiabilidad y control de accesos.

La red conecta una sede central con las sedes de Buenos Aires y La Plata, aplicando buenas prácticas de infraestructura, segmentación lógica y control de tráfico.

---

## 🎯 Objetivos del Proyecto
- Conectar múltiples sedes corporativas
- Segmentar la red por áreas y roles
- Garantizar comunicación confiable entre sedes
- Restringir accesos según políticas de seguridad
- Implementar servicios de red esenciales

---

## 🏢 Topología de la Red
- **Sede Central**
- **Sede Buenos Aires**
- **Sede La Plata**

Las redes internas se conectan mediante enlaces seriales, mientras que las sedes se interconectan utilizando enlaces WLAN.

---

## 🧩 Segmentación y Seguridad
- Segmentación lógica mediante **VLANs por área**
- Restricción de tráfico entre VLANs
- Acceso exclusivo del área de **Sistemas a los servidores**
- Segmentación por roles para fortalecer la seguridad interna

---

## 🔁 Routing
- Routing **estático**
- Routing dinámico mediante **RIP**
- Comunicación total entre sedes, respetando políticas de acceso

---

## 🖥️ Servicios de Red Configurados
- DHCP
- DNS
- Web Server
- Email Server

El direccionamiento IP fue configurado de forma **manual**.
